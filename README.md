# My Portfolio Website

A personal portfolio site showcasing my projects, skills, and experience as a Cloud/DevOps Engineer.

🔗 **Live site:** https://jecintatechworks.com

## Built with
- HTML/CSS
- Cloudflare Workers (static hosting)
- GitHub Actions (CI/CD pipeline — auto-deploys on every push)

## Deployment
This site deploys automatically to Cloudflare via GitHub Actions. Every push to `main` triggers a build and publish using Wrangler.
